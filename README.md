# ⚡ LOE Outage Monitor

Невеликий фоновий застосунок для Windows: стежить за графіками відключень електроенергії
«Львівобленерго» і надсилає зміни в Telegram. Живе в системному треї.

> Неофіційний проєкт, не пов'язаний із «Львівобленерго». Дані беруться з публічного API
> сайту [poweron.loe.lviv.ua](https://poweron.loe.lviv.ua/); формат відповіді може змінитися.

## Можливості

- 🔍 перевіряє графік кожні 60 с (налаштовується) і порівнює з попереднім **по групах і годинах**;
- 📩 надсилає в Telegram зображення графіка та перелік змін: що додано, а що скасовано;
- 📅 окремо обробляє графіки на сьогодні й на завтра;
- 👥 адмін-панель у боті: запити на доступ, користувачі, групи та канали;
- 🛡 токен не потрапляє в журнал, повторні запуски блокуються, стан зберігається між перезапусками.

## Швидкий старт

```bash
git clone <URL-репозиторію>
cd <папка-репозиторію>
pip install -r requirements.txt
python loe_outage_monitor.py
```

1. Створіть бота через [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Дізнайтеся свій числовий Telegram-ID (наприклад, у [@userinfobot](https://t.me/userinfobot)).
3. Під час першого запуску поруч зі скриптом з'явиться `config.json` — впишіть `BOT_TOKEN` та `ADMIN_ID`
   (або скопіюйте `config.example.json`) і запустіть знову.
4. Напишіть своєму боту `/start` — відкриється адмін-панель.

Без консолі: `pythonw loe_outage_monitor.py`.

## Налаштування

Усі параметри — у `config.json`. Будь-який з них можна перевизначити змінною середовища
`LOE_<КЛЮЧ>` (наприклад, `LOE_BOT_TOKEN`) — тоді секрети не доведеться зберігати у файлі.

| Ключ | Обов'язковий | За замовчуванням | Опис |
|---|---|---|---|
| `BOT_TOKEN` | так | — | токен бота від @BotFather |
| `ADMIN_ID` | так | — | Telegram-ID адміністратора |
| `CHAT_ID` | ні | порожньо | основний чат/канал (id або `@username`) |
| `CHECK_INTERVAL_SECONDS` | ні | `60` | інтервал перевірки (мінімум 30) |
| `API_URL` | ні | API «Львівобленерго» | адреса API з графіками |
| `SITE_URL` | ні | `https://poweron.loe.lviv.ua/` | сайт (Referer і пункт меню «Відкрити сайт») |
| `USER_AGENT` | ні | як у браузера | заголовок `User-Agent` для запитів |
| `STATE_RETENTION_DAYS` | ні | `7` | скільки днів зберігати історію графіків |

Окремо `LOE_MONITOR_DIR` задає каталог, де лежать `config.json`, `state.json`, `access.json` і `bot.log`
(за замовчуванням — поруч зі скриптом або `.exe`).

## Доступ і адмін-панель

- Нові користувачі пишуть боту `/start` — адміністратор отримує запит із кнопками «Надати» / «Відхилити».
- Бота в групу чи канал може додати **лише адміністратор**; якщо це зробить хтось інший, бот одразу вийде.
- Сповіщення отримують: адміністратор, `CHAT_ID`, схвалені користувачі та підключені групи.
- Команди адміністратора: `/admin`, `/adduser <id>`, `/removeuser <id>`, `/cancel`.

## Збірка в один .exe

```bash
pip install pyinstaller
python loe_outage_monitor.py --make-icon      # необов'язково: створює icon.ico
pyinstaller --onefile --noconsole --name LoeOutageMonitor --icon icon.ico --add-data "icon.ico;." --hidden-import pystray._win32 --collect-all tzdata loe_outage_monitor.py
```

Готовий файл — `dist/LoeOutageMonitor.exe`. Без `icon.ico` приберіть `--icon` та `--add-data`.

## Тести

```bash
python -m unittest test_loe_monitor -v
```

Тести офлайн: ні мережа, ні Telegram не потрібні.

## Безпека

`config.json`, `state.json`, `access.json` і `bot.log` містять токен, ID та імена користувачів — вони
в `.gitignore`, **не додавайте їх у репозиторій**. Якщо токен колись потрапив у публічний доступ,
перевипустіть його в @BotFather командою `/revoke`.
